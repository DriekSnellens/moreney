## B. Causal event model

```
for event t in chronological order:
  1. release_due(t)          # markouts with available_at <= t
  2. belief = predict(route) # immutable snapshot
  3. decide(take|reject)     # uses belief only
  4. if reject: continue     # NO observe
  5. if take:
       record realized NET
       observe_immediate_roundtrip  # capture / early-stop
       schedule_observation(t+5s)   # adverse for conditional EV
  6. t ← t+1
```

Invariant: `prediction_time < markout_available_at` for every scheduled adverse observation.
